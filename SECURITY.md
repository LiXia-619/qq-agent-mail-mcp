# Security policy

This project is a self-hosted gateway with access to private email. Please review [`docs/SECURITY.md`](docs/SECURITY.md) before deploying it.

Do not report suspected vulnerabilities in a public issue. Use GitHub's private vulnerability reporting or a private Security Advisory for this repository when available. Include the affected version, impact, reproduction steps, and a proposed mitigation if known. Never include real mailbox credentials, messages, attachments, authorization URLs, or access tokens.

The latest release on the default branch is the only supported version. Operators are responsible for securing their hosting account, persistent volume, HTTPS endpoint, DNS, secrets, and Tencent Agent Mail authorization.
